# Learning Activities & Resources

This week I worked on Practical 4 for CP3402 and continued developing my Assignment 1 website using WordPress CMS. My website idea is **Authentic Matcha**, a simple matcha brand website that introduces matcha products, the story of the brand, menu items, and contact information. Since I had previously worked with Joomla, this week I focused on learning how WordPress works differently, especially with pages, templates, menus, themes, and the block editor.

For this practical, I used **LocalWP** to create and edit my WordPress website locally on my computer. I chose LocalWP because it provides an easier local development environment where WordPress, the database, and the server can run together without needing paid hosting at the beginning. This allowed me to practise building and editing the website before publishing it online. I learned that local development is useful because I can test changes safely without affecting a live public website.

At the beginning, I had to install LocalWP and create a new local WordPress site. After the site was created, I opened the WordPress admin dashboard and started editing the website. I learned that LocalWP uses a local domain, so the website can only be accessed on my own computer unless it is later deployed to a real hosting server. This helped me understand the difference between local development and live deployment.

After accessing the WordPress dashboard, I created and edited pages such as Home, About, Menu, and Contact. I also worked on the navigation menu so that visitors could move between pages easily. At first, I had difficulty because clicking About or Contact in the header did not open the correct page. I learned that creating a page is not enough. I also found that sometimes I was editing the page template instead of the actual page content, which caused confusion because the visitor view did not look the same as the editor view.

I customised the website content by replacing the original template text and images with matcha-related content. I changed the banner, headings, descriptions, and product sections to match the **Authentic Matcha** brand. I wrote short descriptions for matcha drinks and non-drink matcha products, such as matcha powder, matcha desserts, and matcha gift sets. I also edited the About page to include a short founder story explaining how the brand started from an interest in high-quality matcha and a desire to share a calm, healthy lifestyle with customers.

During the design process, I faced problems with the WordPress template layout. Some areas were difficult to click or edit because they belonged to template parts instead of normal page content. Sometimes after I saved changes and refreshed the website, the updates did not appear immediately or only the header and footer changed. To solve this, I checked whether I was editing the correct page, template, or reusable block. I also previewed the website from the visitor view to make sure the changes were actually visible.

Another challenge was understanding the relationship between WordPress pages and templates. I learned that page content controls the main body section, while templates can control repeated areas such as the header, footer, and overall layout. This was important because if I edited the wrong area, the page did not change in the way I expected.

Resources used:

* WordPress.org documentation
* LocalWP local development tool
* WordPress dashboard and block editor
* Online tutorials about WordPress pages, menus, themes, and templates
* Browser preview and refresh testing

# Estimated Hours

I estimated that this practical task would take around **1 to 2 days**, because I already had some experience from using Joomla before. However, the actual time was around **3 days** because I faced several problems with LocalWP setup, page linking, template editing, and understanding why some changes were not visible on the visitor page.

# Content Insights

This practical helped me understand how WordPress CMS is used to build and manage a website without writing all the code manually. I learned that WordPress is flexible, but it can also be confusing because pages, templates, menus, themes, and blocks are managed separately.

The most important thing I learned is that a website is not only about adding text and images. It also needs correct structure, navigation, layout, and publishing settings. For example, I learned that if a menu item is not linked correctly, visitors cannot access the page even if the page already exists. I also learned that template editing affects the overall website layout, while page editing affects only the content of one page.

I also learned the importance of local development. Using LocalWP allowed me to build and test my website on my computer before making it public. This is useful because errors can be fixed safely in the local environment first. However, I also learned that a local website is not the same as a live website, so the final project would still need to be deployed to a hosting server if it needs to be accessed by other people.

# Career/Employability/Learning Insights

This activity improved my practical website development skills. In the future, if I work on a web development project, I will know how to set up a local WordPress environment, create pages, customise content, manage menus, and prepare a website for deployment.

I also developed better problem-solving skills because I had to fix errors step by step instead of giving up. When a page did not display correctly, I checked the page settings, menu settings, template parts, and preview mode. This helped me understand how developers test and troubleshoot websites during the development process.

The experience also showed me the importance of testing the website from the visitor’s view. Even if the website looks correct in the editor, it may not appear correctly to users. Therefore, I learned to always preview and test every page after making changes.

Overall, this practical helped me become more confident using WordPress and LocalWP. Although I faced many problems, solving them helped me understand the full process of creating, editing, testing, and preparing a CMS-based website.
