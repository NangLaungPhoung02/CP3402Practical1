# Learning Activities & Resources

This week I worked on Practical 3 and started developing my Assignment 1 website using WordPress CMS. My website idea is an authentic matcha website that introduces different matcha drinks, matcha preparation, and the calm lifestyle connected with matcha culture.

At the beginning, I chose **InfinityFree** to create a free hosting account because I needed a public website link to submit to my tutor. InfinityFree was useful because it allowed me to create a free subdomain and install WordPress without needing to pay for hosting. I used the WordPress installer through the hosting control panel and created my website under the domain for my matcha project.

However, I faced several problems during the setup process. One of the main issues was related to cookies. When I tried to access the WordPress installation or login page, the website showed a message saying that cookies were not enabled. This was confusing because I had already enabled cookies in my browser. I tried to solve the issue by checking Safari settings, disabling private browsing, allowing cookies, and turning off some privacy settings such as blocking cookies or hiding the IP address. I also tried refreshing the page and using another browser to see whether the problem was caused by browser settings.

After setting up the hosting and WordPress website, I started customising the website using the WordPress editor and Pagelayer. I changed the template content, replaced placeholder text, added matcha images, edited the About page, and created sections such as **Why Choose Us**, **Founder**, and a matcha drinks menu. I also wrote short descriptions for different drinks, including Matcha Latte, Matcha Coconut, Strawberry Matcha, Pistachio Matcha, Butterfly Pea Honey Lemon Matcha, Salted Honey Matcha Latte, Frappuccino Matcha, and Matcha Ice Cream.

Since I was still new to WordPress, I spent a lot of time learning how to save changes, edit blocks, replace images, and understand why some updates did not appear immediately after refreshing the website. I learned that cache can sometimes cause the old version of a website to still appear, so I may need to clear the browser cache or wait before checking the updated website.

# Estimated Hours of Explicit Learning Activity

I originally estimated that this practical would take approximately **1.5 days (12 hours)** to complete.

However, the actual time spent was approximately **3 days (24 hours)** because I was new to WordPress hosting and needed extra time to create the InfinityFree hosting account, install WordPress, fix cookie issues, understand the editor, replace default template content, and customise the website appearance.

The cookie issue and hosting setup took longer than expected because I had to test different browser settings and check whether the problem was caused by Safari, privacy settings, or the hosting platform. Editing the website also took additional time because I needed to choose suitable images and write content that matched the matcha theme.

# Content Insights

One of the most interesting things I learned this week was how WordPress can be used to create a website without writing a full HTML, CSS, and JavaScript project from the beginning. Before using WordPress, I thought website development always required a lot of coding. However, WordPress allowed me to edit pages visually, add images, change text, and organise content more easily.

I also learned that hosting is an important part of website development. Creating the website locally or designing it inside WordPress is not enough if I need to submit a public link. By using InfinityFree, I learned how free hosting works and how a CMS website can be installed on a live server.

Another important insight was understanding that website templates often contain placeholder content. At first, I saw text that looked like Latin and did not understand what it meant. Later, I learned that this was only sample text used by the template, and I needed to replace it with my own content. This helped me understand that customising a website is not only about changing images, but also about making sure the words, layout, and theme match the business idea.

For my matcha website, I focused on creating a fresh, calm, and natural feeling. I used words such as smooth, fresh, relaxing, natural, healthy, and authentic to match the style of the brand.

# Career/Employability/Learning Insights

This practical helped me understand why Content Management Systems such as WordPress are widely used in real website development. Many small businesses, cafés, stores, and personal brands need websites that can be edited easily without hiring a developer for every small change. WordPress is useful because it allows users to manage pages, images, text, and menus through an admin interface.

Learning how to use InfinityFree also gave me experience with hosting and publishing a website online. This is useful because future employers or clients may expect a website to be accessible through a live link, not only stored on a local computer. I also learned that technical problems such as cookies, cache, browser settings, and login issues are common parts of web development.

As someone who is still learning web development, this practical improved my confidence in using CMS platforms. It showed me that professional website development is not only about coding, but also about choosing the right platform, setting up hosting, designing pages, writing suitable content, and solving technical issues.

Although I found WordPress and InfinityFree challenging at first, I now understand the process better and feel more confident using a CMS to build a simple business website. In the future, I think WordPress could be useful for creating small business websites, portfolios, blogs, or online product pages.
