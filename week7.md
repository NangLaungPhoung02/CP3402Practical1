# Week 7

## Learning Activities & Resources

This week I completed the PHP practical by forking my lecturer's **The Advice Shop** project and modifying it into my own version. Instead of creating a website from scratch, I customised the existing project by changing the homepage content, adding two new pages (Study Tips and Wellbeing), and modifying the navigation menu. My main focus was learning how PHP works together with HTML and CSS to create dynamic webpages.

During this practical, I also explored several PHP concepts, including using **echo** to display HTML content, **if/else** statements for decision making, **for**, **while**, and **foreach** loops for repetition, functions with parameters, and using **include** to reuse common files such as the header, navigation bar, and footer. I also referred to PHP documentation and online tutorials to better understand PHP syntax and debugging.

## Estimated Hours of Explicit Learning Activity

I estimated that I would spend around **4 hours** completing this practical because the lecturer already provided a starter project. However, I actually spent approximately **1.5 to 2 days** working on it.

Most of my time was spent understanding how the existing project was organised before making any modifications. Since I had not worked with PHP before, I first needed to understand how different PHP files were connected through the `include` function. I also spent considerable time debugging layout issues after modifying the pages. For example, when I created my new Study Tips page, the CSS styling did not load correctly because I forgot to include the required HTML structure and stylesheet. Later, I also encountered layout problems caused by the original CSS, such as fixed content widths, floated images, and page alignment. I had to carefully inspect the CSS rules, experiment with different layouts, and repeatedly refresh the browser to verify that my changes worked correctly.

## Content Insights

Through this practical, I developed a much better understanding of the basics of PHP. Before this task, I mainly worked with HTML and CSS, but this was my first experience using PHP to generate webpage content dynamically.

I learned how the **echo** statement can output different HTML elements directly from PHP, making it possible to mix programming logic with webpage content. I also learned how **if/else** statements can display different messages depending on conditions, while **for**, **while**, and **foreach** loops allow repetitive tasks to be completed efficiently without writing the same code multiple times.

Another important concept I learned was creating **functions with parameters**, which helped me understand how code can be reused instead of repeating similar sections throughout a project. I also gained practical experience using the **include** statement to reuse the same header, navigation bar, and footer across multiple pages. This demonstrated how larger websites avoid duplicating code and make future maintenance much easier.

In addition to learning PHP, I also improved my understanding of how PHP, HTML, and CSS work together. I discovered that although PHP generates the webpage content, the page appearance still depends on correctly linked CSS files. Debugging these issues helped me better understand webpage structure, styling, and the relationship between backend and frontend development.

## Career / Employability / Learning Insights

This practical helped me understand how server-side programming differs from static webpage development. Unlike HTML pages, PHP allows webpages to generate different content depending on variables, conditions, and user interactions. These skills are widely used in many web applications and content management systems.

I also realised the importance of reading and understanding existing code before making changes. In this practical, I worked from an existing project rather than starting from scratch, which is similar to real software development where developers frequently maintain and extend existing systems. Understanding the original project structure before adding new features was an important learning experience.

Another valuable lesson was improving my debugging skills. Many of the problems I encountered were not caused by PHP itself but by CSS layout rules and the interaction between different files. Learning how to identify the source of these issues through testing and careful observation improved my confidence in solving technical problems independently.

Overall, this practical strengthened both my programming knowledge and my problem-solving skills. It also provided a better understanding of how frontend and backend technologies work together, which will be valuable for future university projects and professional web development.
