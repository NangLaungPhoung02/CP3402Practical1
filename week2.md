This week I worked on Practical 2 and started developing my Assignment 1 website using Joomla CMS. Since I had never used Joomla before, I spent a significant amount of time learning how the platform works and understanding the relationship between articles, menus, modules, templates, and pages.

To solve these problems, I used the Joomla documentation, online tutorials, and additional web resources to guide me through the setup process.

After successfully installing Joomla, I created a simple website for my startup idea, **Cask & Co.**, a premium online alcohol store. I customised the website by creating pages, adding content and images, editing menus, changing colours, and learning how Joomla templates can be modified without writing large amounts of code.

However, the actual time spent was approximately **3 days (24 hours)** because I was completely new to Joomla and needed additional time to troubleshoot installation problems, learn the CMS structure, and customise the website appearance.

# Content Insights

One of the most interesting things I learned this week was how different a Content Management System is from traditional web development. Before this practical, I assumed that building a website required extensive HTML, CSS, and JavaScript coding. I was surprised to discover that Joomla allows many website features to be created and managed through its administrative interface.

I learned how Joomla organises website content through articles and menu items, and how templates control the overall appearance of a website. I also learned how modules can be used to display content in different locations without manually coding each page.

Another important insight was that website development is not only about writing code. Planning content, organising navigation, selecting layouts, and maintaining a consistent design are equally important aspects of creating a professional website.

# Career/Employability/Learning Insights

This practical helped me understand why Content Management Systems such as Joomla are widely used in industry. Many businesses require websites that can be updated easily without needing a developer to modify code for every small change. Joomla provides an efficient way to manage website content while still allowing customisation when required.

As someone who has mostly worked with programming languages and coding assignments, learning Joomla broadened my understanding of web development tools. It showed me that professional web development often involves selecting the right platform for a project rather than always building everything from scratch.

I believe the knowledge gained from this practical will be valuable for future projects and employment opportunities because CMS platforms are commonly used by organisations for managing websites. Although I found Joomla challenging at first, I am now more confident using it and would consider using it again for future website development projects.
