Week 5 – WordPress Child Themes

Learning Activities & Resources

This week I learned how to create a WordPress child theme and understand the relationship between parent and child themes. I completed the practical using LocalWP, where I created a child theme by adding the required `style.css` and `functions.php` files. I also applied CSS customisations to modify the website appearance without changing the original parent theme. During the practical, I referred to the WordPress documentation and lecture materials to better understand the correct structure of a child theme and how WordPress loads parent and child theme styles.

**Resources**

* WordPress Developer Documentation – Child Themes
* CP3402 Practical Notes
* LocalWP Documentation

## Estimated Hours of Explicit Learning Activity

I estimated that I would spend approximately **2 hours** completing this practical. However, I spent around **4 hours** learning and testing different approaches before successfully creating and activating the child theme.

A significant amount of time was spent understanding the relationship between parent and child themes. Initially, I attempted to create a child theme using another child theme as the parent, which caused activation errors. After identifying the correct parent theme, I recreated the child theme and successfully applied my customisations. I also spent additional time testing CSS changes and ensuring the custom styles were loaded correctly.

## Content Insights

Through this practical, I developed a clearer understanding of how WordPress themes are organised and why child themes are recommended when customising websites. I learned that a child theme allows developers to safely modify the appearance of a website while preserving the original parent theme, making future updates easier to manage.

I also improved my understanding of how WordPress loads stylesheets through the `functions.php` file and how CSS can be used to customise different visual elements of a website. This practical strengthened my knowledge of theme structure, stylesheet organisation, and the importance of following best practices when developing WordPress websites.
