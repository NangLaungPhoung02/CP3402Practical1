## Week 8 – Learning Experiment and Presentation Rehearsal

### Learning Activities & Resources

This week, I conducted a learning experiment while working on the frontend development of our group WordPress project.

### Learning Experiment

**Hypothesis**

My hypothesis was that planning the structure of a webpage before starting to code would help me complete the frontend development more efficiently and with fewer mistakes than starting to code immediately.

**Experiment**

To test this hypothesis, I used two different approaches while working on WordPress frontend tasks.

For the first task, I started coding without making a detailed plan. I created the page and adjusted the HTML/PHP and CSS while developing it. When I encountered layout or styling problems, I fixed them as I went.

For the second task, I spent approximately 10–15 minutes planning before coding. I identified the page structure, the WordPress/PHP elements I would need, the CSS classes I planned to create, and how I wanted the final layout to look. After making this plan, I started implementing the page.

During both tasks, I observed:

* how long the development took
* how many problems or errors I encountered
* how often I needed to rewrite or change my code
* how easy it was to understand what I needed to do next

### Results

The planned approach was more organised and easier to follow. Although I spent additional time planning before coding, I spent less time deciding what to do while developing the page.

I also found that I made fewer unnecessary CSS changes because I already had an idea of the page structure and the classes I needed. In comparison, when I started coding immediately, I changed the structure and styling several times.

Based on my experiment, my results supported my hypothesis. Planning before coding made my development process more structured and reduced unnecessary rework.

### Learning Insights

This experiment helped me understand that learning programming is not only about writing code. Planning and breaking a problem into smaller tasks can also improve the development process.

Previously, I sometimes started coding as soon as I understood the basic requirement. This experiment showed me that spending a small amount of time planning can save more time later.

I will continue using this approach for the remaining frontend development of our project. Before implementing a new page or feature, I will first identify the required files, page structure, styling requirements, and expected result.
