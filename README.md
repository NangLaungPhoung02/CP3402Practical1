# 🍷 Premium Online Alcohol shop Website

## 📌 Project Description
This project is a front-end website for a premium online alcohol store.  
It showcases a variety of alcoholic beverages such as  whisky,vodka,beer, baijiu, gin, and tequila, including their prices, origins, and taste descriptions.

The website is designed with a focus on user experience, clean layout, and responsible drinking awareness. It is developed as part of a university assignment.

---

## 🎯 Features
- 🛍️ Product listing (wine, champagne, baijiu, whisky, Vodka, Gin, Tequila,beer etc.)
- 🖼️ Product images with descriptions
- 💲 Price display for each product
- 🔞 Age restriction warning (18+)
- 📄 Multiple pages (Home, Products, Contact)
- 📱 Responsive and simple layout
- ⚖️ Legal disclaimer included
